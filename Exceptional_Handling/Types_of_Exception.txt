Exception are Unwanted Event which occurs during Program Execution it stops Normal flow of
Program ..
WE Have a Diffrent Types of Exception Are ...

1) Complie Time Error .
      -> In which it occurs when we do the Spelling Mistake and error in Syntax This are called Complie Time Error..


2) Run Time Error..
      ->Which occurs During a Execution or it due to invalid Operation Unexpected Syntax..

      Common Cause of this by ..
      ->Divided by Zero Error & Array index out of bound..

3) Logical Error..
    -> In Which Logical Error is Logical of Program Where code Runs Succcesfully out wrong Output ..
