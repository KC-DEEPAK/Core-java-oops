# Core Java - OOP Concepts

A comprehensive Java learning project covering fundamental Object-Oriented Programming (OOP) concepts and core Java features.

## 📋 Project Overview

This project contains Java implementations demonstrating various OOP principles and core Java concepts. It's designed as a learning resource for understanding fundamental Java programming and object-oriented design patterns.

## 📁 Project Structure

### Core Concepts
- **Abstraction & Inheritance**
  - `Abstract.java` - Abstract class implementation
  - `Abstract_Anonymous.java` - Anonymous inner classes with abstraction
  - `Inheritance.java` - Inheritance patterns and usage

- **Encapsulation & Access Control**
  - `Encapsulation.java` - Data hiding and encapsulation principles
  - `Access_Modifiers.txt` - Access modifier documentation

- **Polymorphism**
  - `Method_Overriding.java` - Method overriding implementation
  - `Dynamic_method.java` - Dynamic method dispatch
  - `Overloading.java` - Method and constructor overloading

- **Classes & Objects**
  - `Create_Object.java` - Object creation patterns
  - `Constructor.java` - Constructor implementation
  - `Parameterized.java` - Parameterized constructors
  - `Anonymous_Object.java` - Anonymous object usage
  - `Anonymous_inner_class.java` - Anonymous inner class implementation

- **Interfaces**
  - `Interface.java` - Basic interface definition
  - `Interface_2.java` - Multiple interfaces
  - `Types_of_Interface.java` - Different interface types
  - `Need_of_Interface.java` - Why interfaces are needed
  - `Functional_Interface.java` - Functional interfaces (Java 8+)

- **Collections & Data Structures**
  - `Array.java` - Array basics
  - `Multi_dimensional.java` - Multi-dimensional arrays
  - `Jagged.java` - Jagged arrays
  - `Object_Array.java` - Arrays of objects
  - `String_Buffer.java` - StringBuffer usage
  - `Strings.java` - String manipulation

- **Advanced Features**
  - `Enum.java` - Enumeration basics
  - `Enum_class.java` - Enum class implementation
  - `Enum_Condition.java` - Conditional enum usage
  - `Lambda_Expression.java` - Lambda expressions (Java 8+)
  - `Lambda_return.java` - Lambda with return statements
  - `Threads.java` - Multi-threading implementation
  - `Wrapper_class.java` - Wrapper classes
  - `Final_Keyword.java` - Final keyword usage
  - `Static.java` - Static members
  - `Static_Method.java` - Static method implementation
  - `Static_Block.java` - Static block initialization
  - `This_keyword.java` - This keyword usage
  - `Super.java` - Super keyword usage
  - `Annotation.java` - Annotations usage

- **Input & Output**
  - `Input_From_User.java` - User input handling
  - `Enhanced.java` - Enhanced for loop

- **Exception Handling** (`Exceptional_Handling/`)
  - `Exception_handling.java` - Try-catch blocks
  - `Multiple_Catch.java` - Multiple catch blocks
  - `Throw_Keyword.java` - Throw keyword usage
  - `Throws_Keyword.java` - Throws keyword declaration
  - `Types_of_Exception.txt` - Exception types documentation

- **Packages** (`Package/`)
  - `Demo.java` - Package demonstration
  - `tools/` - Custom package with utilities
    - `Calc.java` - Basic calculator
    - `AdvCalc.java` - Advanced calculator

## 🚀 Getting Started

### Prerequisites
- Java Development Kit (JDK) 8 or higher
- A Java IDE (IntelliJ IDEA, Eclipse, VS Code) or command-line compiler

### Compilation & Execution

To compile a Java file:
```bash
javac FileName.java
```

To run a Java program:
```bash
java ClassName
```

For packaged classes:
```bash
javac Package/Demo.java
java Package.Demo
```
